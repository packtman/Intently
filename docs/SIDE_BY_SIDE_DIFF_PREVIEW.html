💡 Implementation Notes

  • Contextual Insertion: Suggestions are inserted at semantically appropriate locations (near related content), not appended at section end - just like code edits
  • Keyword Matching: System analyzes finding keywords to find related content in PRD (e.g., auth suggestions near auth bullets)
  • Smart Fallback: If no related content found, inserts after existing bullets or before subsections
  • Backend Integration: When user clicks "Accept", send PUT request to /api/prd/{id}/apply-suggestion with the diff
  • File Update: Backend reads original .md file, applies changes, writes updated file back to disk
  • Real-time Sync: WebSocket or polling to show "Syncing..." → "Synced ✓" status
  • Undo Support: Keep backup of original file for 24 hours to support undo
  • Conflict Detection: Check if file was modified externally before applying changes
  • Line-by-line Accept: Each line in the diff can be individually accepted/rejected
